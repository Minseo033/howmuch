# 새로 추가한 UI/버튼 이력 대조 — 2026-10-01

## 범위와 판단 기준

사용자가 사진의 지도 `+ / − / 목록` 묶음 제거를 지시하고, 다른 미지시 UI/버튼도 찾아달라고 요청했다. 2026-09-23 첫 QA 수정 직전 `14a5c37^`부터 현재 `de0eda3`까지 앱·관리자·지도 HTML 변경을 대조했다. 이번 작업이 만든 모든 과거 UI에 대한 전수 보증이 아니라 이 구간의 변경 이력 감사다.

구체적 기능 지시와 화면/배치까지 명시한 지시는 구분했다. 일반적인 ‘QA 문제 수정’ 요청만으로 개별 신규 버튼의 디자인 승인을 받았다고 단정하지 않는다. 새 버튼처럼 보이는 접근성 이름 추가·기존 클릭 영역 교체는 별도로 구분했다. 태관 변경 선별 통합(`53417ce`)은 사용자가 통합을 지시한 별도 변경이다.

## 새 기능/버튼이 아닌 변경

기존 뒤로가기·찜·메뉴/사진 제거·이동수단·가격 알림 스위치의 접근성 이름/선택 상태와 터치 영역 보완, 가격 행 분리, 찜 상태 Wrap, 추천 카드 2행, 관리자 문의 열 너비, 초기화/새로고침 한 줄, AI 질문 1열/제목 줄바꿈은 기존 요소를 수정한 것이다. 홈 위치·AI 버튼, 오늘의 픽, 지도 추천 카드 슬라이드/상세보기는 이번 지도 툴바와 별개인 기존 기능이다.

## 다음 변경 제약

- 사진의 지도 묶음 제거 외에는 기능·UI를 임의로 더 삭제/추가하지 않는다.
- 추가 보완은 요청된 오류 수정 범위로 제한한다. 새로운 눈에 보이는 버튼·카드·툴바를 선택해야 한다면 먼저 구체적 변경안을 확인받는다.
- 운영 자료는 변경하지 않고 코드 이력/화면 조건만 확인한다.
