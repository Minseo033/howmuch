## 기존 제약 및 후속 판단

- 기존 리뷰가 매장명을 식별자로 사용하므로 동명 매장 분리에는 안정 ID 전환과 레거시 데이터 대응이 필요하다. 기존 리뷰를 오배정하지 않도록 데이터 마이그레이션은 이번에 실행하지 않았다.
- 네이버/애플 로그인, 완전한 오프라인 저장, 웹 종료 후 시스템 푸시는 현재 구현 대상/지원 범위와 별도인 기존 미지원 기능이다.
- 통과한 자동 검사가 모든 운영 데이터나 실제 기기 환경의 무결함을 보장하지는 않는다. 운영 계정·제보·영수증 데이터를 테스트 목적으로 생성/삭제하지 않았다.
