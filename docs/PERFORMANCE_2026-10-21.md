# 2026-10-21 조회 대기·탭 복귀 성능 개선

## 판단과 적용 범위

사용자가 전달한 운영 QA(리포트 통계 6.2/6.2/7.8초, 마이 통계 약 3.5초)는 수정 전 관측값이다. 이번 작업에서 같은 운영 계정으로 전후 시간을 직접 재측정한 값으로 취급하지 않는다.

효과가 가장 확실한 곳은 선택하지 않은 데이터에 대한 대기, 탭을 바꿀 때의 화면 재생성, 같은 이력의 중복 조회, 전국 카탈로그의 불필요한 상세 정보다. 이 네 경로와 네이티브 시작 전 대기를 수정했다. 화면 전환 시간을 추가로 줄이는 변경은 하지 않았다.

## 데이터 정합성

- 로그아웃·로그인·세션 복원 때 메모리 요청 캐시를 폐기한다. 이전 계정의 늦은 응답은 새 계정의 요약과 섞지 않는다.
- 찜·제보·목표·프로필·방문 변경 성공 시 관련 조회 캐시를 무효화한다. 영수증 multipart 제출도 별도로 무효화한다.
- 조회 중 방문 변경이 생기면 과거 통계 결과를 표시하지 않고 새 조회로 갱신한다. 프로필 수정·계정 관리 복귀는 신선한 TTL 안이어도 다시 확인한다.
- 서버는 승인·방문 삭제·탈퇴 후 visits 캐시를 무효화한다. 이미 진행 중이던 이전 조회는 새 세대의 데이터로 다시 읽어 반환한다.
- 서버 캐시의 256명 상한은 완료된 사용자에 적용한다. 진행 중 조회는 합류할 수 있도록 보존하며, 동시에 대기 중인 사용자가 많으면 일시적으로 이를 넘을 수 있다.
- 지도용 경량 응답과 `/all` 응답은 다른 ETag를 사용한다. 원본 목록을 수정하지 않으며, 이전 서버가 새 경로에 404/405를 반환하면 `/all`로 전환한다.
- 외부 관리자 변경을 앱에 즉시 푸시하는 구독은 추가하지 않았다. 사용자는 탭 재진입·명시적 새로고침·TTL 만료 시 새 값을 조회한다.

## 전송량 측정

현재 공개 `/api/stores/all`에서 저장한 11,391개 표본을 동일하게 다시 직렬화하고 `openingHours`만 제거해 비교했다. 매장 개수와 다른 필드는 전부 동일함을 검사했다. 원본 매장 JSON은 저장소에 추가하지 않았다.

| 측정 항목 | 전체 응답 | 지도 응답 | 차이 |
|---|---:|---:|---:|
| 매장 수 | 11,391 | 11,391 | 동일 |
| JSON bytes | 10,092,833 | 5,584,651 | −44.7% |
| gzip bytes (level 9) | 1,503,010 | 1,080,373 | −28.1% |
| 로컬 Node JSON.parse 중앙값 | 19.83ms | 12.35ms | 참고값 |

재현 도구: `node scripts/measure_store_catalog_payload.mjs <저장한 공개 카탈로그 JSON 경로>`. 1회 준비 후 10회 해석한 중앙값이며 기기·부하에 따라 달라진다. 브라우저 프레임, Flutter 모델 변환, 실제 통신 시간의 전후 측정으로 해석하지 않는다. QA의 10.1MB·압축 1.54MB와 약간 다른 값은 재직렬화·압축 설정 차이다.

## 검증

선택 기간 우선 표시, 늦은 부가 응답, 탭 유지·미방문 탭 미생성, 마이 재진입 호출 수, 다른 계정의 늦은 응답 차단, 방문 변경 도중 응답 무효화, 저장 목표 즉시 반영, 서버 동시 조회·삭제 무효화, 상세 영업시간 복원, 전국 검색 필드 보존을 자동 검사한다.

최종 검사 수와 빌드 결과는 `PROJECT_STATUS.md` 5-150에 기록했다. 운영 자료 생성·수정, 실기기 조작, 배포 전후 운영 계정의 지연 측정은 이번 작업에서 수행하지 않았다. 사용자 요청으로 운영 API 비교 검사는 실행하지 않았다.

## 이번에 적용하지 않은 제안

- 월별 집계 문서: 기존 이력을 다시 계산하는 정확성을 유지하면서 중복 조회부터 제거했다. 방문 이력이 더 커져 집계 자체가 병목임을 확인하면 승인·삭제·재시도와 함께 별도 설계한다.
- 웹 폰트·Web Worker·카카오 SDK 지연 로드: 현재 전체 한글 폰트는 약 10.4MB이며 추가 개선 여지가 있다. 문자 일부만 남기는 변경은 하지 않았고, 전체 글리프를 유지하는 웹 전용 압축·배포 단계와 최초 렌더링 호환성은 별도 검증이 필요하다. 이번 성능 개선 수치에 폰트 감소를 포함하지 않는다.
- 네이티브 카탈로그 6시간 캐시·별도 isolate는 기존 기능을 유지했다. 새로 도입한 개선으로 계산하지 않는다.
- 앱 실기기 profile/release 첫 화면 시간·프레임, Render 절전 및 리전 지연은 미측정이다. 시뮬레이터 빌드는 기기 성능 측정을 대신하지 않는다.
