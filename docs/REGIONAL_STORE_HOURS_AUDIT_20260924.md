# 전국 착한가격업소 영업시간 공개자료 점검 (2026-09-24)

## 확인 범위와 한계

- 공공데이터포털의 `착한가격업소` 파일 검색 결과 199개 중 관련 파일 126개의 **데이터 컬럼**을 확인했다. 영업시간 또는 시작·종료시간 컬럼이 있는 파일은 9개였다. 이는 해당 검색 결과의 파일자료 점검이며, 모든 지자체 내부 자료의 존재 여부까지 보증하지 않는다.
- 행정안전부 전국 현황 파일(2026-06-30, 12,645행)은 업소명·주소·메뉴·가격을 제공하지만 영업시간 컬럼이 없다. 따라서 전국 모든 업소의 시간을 공개 파일만으로 완성할 수 없다.
- 일부 지역은 공공데이터포털 API로 시간을 제공하지만 서비스 키가 필요하거나 자료가 오래됐다. 공식 착한가격업소 사이트의 개별 상세를 1만 건 이상 자동 호출하는 방식은 실행 승인이 거절되어 사용하지 않았다.

## 확인했지만 반영하지 않은 파일

- [울산광역시 울주군](https://www.data.go.kr/data/3075457/fileData.do): 2024-09-02 기준. 현재 영업시간으로 보기에는 오래됐다.
- [전북특별자치도](https://www.data.go.kr/data/15055669/fileData.do): 2020-10-13 기준. 기존 업소와 정확 일치도 없었다.
- [경상남도 합천군](https://www.data.go.kr/data/3069023/fileData.do): 2020-09-21 기준. 일치하는 업소가 일부 있어도 너무 오래된 시간을 노출하지 않았다.

## 적용 규칙과 재검증

- 이름과 주소를 정규화한 값이 **각 자료와 기존 카탈로그에서 각각 유일하게 일치**해야 한다. 양쪽 전화번호가 있는데 불일치하면 제외한다. 이름만 비슷한 후보는 적용하지 않는다.
- 이미 영업시간이 있는 기록은 덮어쓰지 않고, 더 최근의 울산 남구 자료를 2025년 울산 광역자료보다 우선한다. 빈 값과 시간 문법 오류도 제외한다.
- 원본 파일은 저장소에 포함하지 않았다. 가져오기 스크립트가 각 파일의 SHA-256과 행 수를 검증하며 기본값은 미리보기다. 원본 5개를 `/tmp`에 내려받아 `python3 scripts/import-regional-store-hours.py --source-dir /tmp --write`로 재현할 수 있다.
- 백엔드 출처 검증은 각 제공기관명과 공공데이터포털의 정확한 자료 경로 조합만 허용한다. 카탈로그 총 10,635건, 사진·주차 등 기존 정보, 매장 식별자는 유지한다.
- 운영 검증: `13328c6` 배포 후 `/healthz`에서 동일 커밋을 확인했다. `scripts/verify-store-hours.mjs`가 운영 전체 매장 11,397건과 지도 범위 응답을 대조해 영업시간 474건을 포함한 보완 기록 10,635건 모두 일치함을 확인했다.

## 추가 점검: 2025~2026년 지자체 최신 현황

공공데이터포털 파일명 검색에서 빠졌던 **지자체 자체 누리집**도 전국 지역을 대상으로 찾아 확인했다. 확인한 자료 중 업소명·주소·영업시간과 기준 시점을 함께 검증할 수 있는 네 자료만 추가했다. 전국 지자체 누리집 전체를 빠짐없이 조사했다는 뜻은 아니다.

**실제 시간 보유 매장 474→529건(+55)**. 목포 페이지에는 더 오래된 사진이 있는 항목도 있어 2025-11-17로 표기된 항목만 후보로 삼았고, 이 날짜는 영업시간 자체의 갱신일을 보증하지 않는다. 적용 날짜도 2025-11-17로 보수적으로 표기한다. 진도는 기준 월만 공개되어 해당 월의 첫날로 표기한다. 90일 초과 정보는 앱에서 오래된 정보 경고를 표시한다.

`scripts/import-recent-municipal-hours.py`가 원본 4개 파일의 SHA-256·행 수를 검사하고, 기존 매장과 **상호명 + 도로명/건물번호가 유일하게 일치**하며 양쪽 전화번호가 충돌하지 않는 항목만 반영한다. 기존 시간·사진·편의정보는 덮어쓰지 않는다. 이름만 같거나 전화번호가 달라 불확실한 매장은 제외했다. 네 자료의 원본 파일은 저장소에 포함하지 않았으며 `/tmp`에 내려받은 뒤 기본 미리보기, `--write` 옵션으로 재현한다. 전국 전체 영업시간 확보는 여전히 미완료이며 남은 매장은 정보 없음으로 유지한다.
