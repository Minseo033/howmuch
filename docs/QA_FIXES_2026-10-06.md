## 추가 발견·수정

1. 새 제보 저장 완료 화면이 목록 첫 번째 과거 제보를 표시했다. 제출 ID로 연결하고 모든 서버 저장 메뉴를 표시한다. 다른 과거 제보/무료 4번째 메뉴를 포함하는 회귀 검사 통과.
2. 관리자 처리 직후 상세 재진입이 캐시의 검토 중 상태를 유지했다. 상세 진입에서 조회 1회로 최신 상태를 반영한다. 저장 요청 재시도는 하지 않는다. 실패하면 기존 자료를 보존한다. 수정 전 검사 실패를 확인한 뒤 수정 후 통과.
3. 신고 설명이 일반 정보 행의 한 줄 말줄임을 물려받았다. 해당 행만 줄바꿈해 전문 표시. 최종 17 Pro 실화면 확인.
