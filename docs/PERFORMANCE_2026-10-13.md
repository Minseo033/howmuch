# 지도·오늘의 픽 성능 개선 (2026-10-13)

## 문제와 변경

사용자가 오늘의 픽 진입과 매장이 많은 곳으로 빠른 지도 이동 시 끊김을 보고했다. 일반 지도 이동은 이미 서버 재조회와 Flutter 전체 마커 재생성을 피하고 있었으나, 웹·앱 WebView의 라벨 갱신은 전국 매장 전체를 돌며 매번 지도 범위를 조회했다. 앱에서는 전체 매장 수만큼 DOM 요소를 조회했고 기존 라벨도 다시 지도에 붙였다.

- 전체 매장을 클러스터에 유지한다. 100개 노출 제한은 추가하지 않는다.
- 매장 위도 인덱스를 카탈로그 갱신 시 한 번 만들고, 라벨 갱신 시 지도 범위를 한 번만 읽어 해당 위도 구간과 경도 안의 매장만 찾는다.
- 이전 화면과 비교해 들어오고 나간 라벨만 부착·제거한다. 강조 스타일은 실제 선택 상태가 바뀐 라벨만 갱신한다.
- 화면 밖 라벨 재사용 캐시는 최대 512개 또는 현재 표시 중인 라벨 수로 제한한다. **실제 화면의 매장 표시 수 제한이 아니다.**
- 클러스터용 투명 마커의 개별 클릭 리스너를 없앤다. 클릭은 기존 사용자 정의 라벨과 클러스터에서 처리하며 기본 핀 숨김·확대 시 매장 카드 선택을 유지한다.
- 카탈로그가 같으면 반복 위치 중심 이동 때 Flutter에서 전국 마커 JSON을 다시 만들지 않는다. 홈을 가리는 화면이나 앱 백그라운드에서는 카탈로그 렌더링을 보류하고 복귀 시 최신 데이터를 반영한다. 앱 WebView는 가려진 동안 자체 라벨·범위 갱신도 보류한다.
- 오늘의 픽 정상 결과를 동일 좌표·반경·날짜에 한해 메모리에서 1분 재사용하고 진행 중인 같은 요청을 공유한다. 위치나 반경 변경, 날짜 변경, 만료, 명시적 재시도는 새로 조회한다. 오류는 캐시하지 않고 최대 8개 결과만 유지하며 AI 루트에는 적용하지 않는다.
- 서버 추천의 세 후보군에서 매장별 거리를 한 번 계산해 공유한다. 추천 거리 경계·메뉴/날씨 정책·정렬 결과는 유지한다.
- 앱의 대용량 매장 JSON 해석과 로컬 캐시 직렬화는 별도 isolate에서 실행한다. 웹의 compute는 메인 스레드에서 실행되므로 웹 JSON 해석의 백그라운드 실행을 주장하지 않는다.

## 증거

15,000개 매장, 현재 화면 150개 라벨, 동일 화면 20회 갱신을 모의 SDK에서 비교했다.

| 지표 | 이전 | 변경 후 |
| --- | ---: | ---: |
| 지도 범위 조회 (웹·앱) | 300,000회 | 20회 |
| DOM 요소 조회 (앱) | 300,000회 | 0회 |
| 변경 없는 라벨 재부착 (웹·앱) | 3,000회 | 0회 |

모의 SDK와 Node 실행에서의 **연산 수 검증**이다. 실제 iPhone/Safari FPS나 체감 지연 개선 비율을 측정한 결과는 아니다. 카카오 SDK의 전체 클러스터 계산과 최초 네트워크 다운로드 시간은 여전히 존재한다.

추가로 60회 빠른 이동에서 현재 영역의 모든 라벨과 선택 매장 유지, 화면 밖 캐시 제한, 전국 15,000개 클러스터 참여 및 기본 마커 숨김을 확인한다. 서버 테스트는 400개 후보의 좌표 조회 횟수를 제한하고 기존 가까운 순 추천을 검증한다.

## 로컬 검증

- Flutter 전체 테스트 942개 통과 (관련 지도/카드/추천/캐시/위치 접근성 흐름 95개 포함).
- Node 테스트 전체 66개 통과 (신규 성능·기존 지도 수명주기·관리자·배포 검증 포함).
- 백엔드 테스트 전체 426개 통과 및 bootJar 생성 성공.
- Dart lib/test 전체 분석: 문제 없음. 로컬 Flutter analyze는 분석 서버 입력 스트림 오류로 종료되어 Dart 분석을 사용했으며 CI에서 Flutter analyze를 추가 확인한다.
- 웹 릴리스 빌드 성공. Chrome 브라우저 테스트/iOS 빌드 및 운영 배포 결과는 이번 PR의 CI와 후속 기록에서 확인한다.
- 로컬 IAB에서 홈과 오늘의 픽 진입 및 위치 없는 오류 안내 흐름을 확인했다. 로컬 주소의 카카오 SDK를 불러오지 못해 실제 지도 이동 체감은 이 확인에 포함하지 않는다. 위치 권한을 새로 허용하거나 실기기를 사용하지 않았다.
- 운영 방문·찜·영수증·매장 자료를 생성하거나 변경하지 않았다.
