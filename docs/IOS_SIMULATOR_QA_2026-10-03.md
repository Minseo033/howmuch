## 판정과 범위

**진행 중. 전체 QA 통과/완료가 아니다.** 재부팅 후 현재 소스와 실행 상태를 다시 확인한 실행이다. 10/2의 약관·로그인 대기 기록은 당시 상태로 보존한다. 이번 실행에서는 기존 카카오 세션이 복원돼 게스트 없이 진행한다. 데이터 변경 허용 범위에서 실제 버튼으로 저장·재진입을 점검하고 원복/남은 자료를 구분한다. 새 UI·기능 및 기능 코드 변경은 하지 않는다.
